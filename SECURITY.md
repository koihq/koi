# Security policy

Please report security problems privately, through GitHub's
[private vulnerability reporting](https://github.com/koihq/koi/security/advisories/new). Do not
open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We will
acknowledge the report and tell you what we plan to do about it.

Security fixes land on `main` and in the next release. Self-hosted instances should stay on the
latest released image.
